# SysMonitor

Monitor local de rede, CPU, GPU e memória para Windows com HVCI (Python, Tkinter, bandeja).

**Antes de qualquer tarefa, leia [docs/agentes/INDICE.md](docs/agentes/INDICE.md) e, pela tabela
"Se a tarefa mexe em… leia…", só os arquivos da área da tarefa.** Não leia o projeto inteiro.

Regras invioláveis:
- Sem push, tag ou release sem autorização do Mateus.
- Manter compatível com HVCI e sem privilégio elevado.
- Segredos nunca em docs nem commits; logs, cache e `backup/` fora dos commits.
- Ao fechar um marco: atualizar `docs/agentes/estado.md` e as áreas tocadas.
